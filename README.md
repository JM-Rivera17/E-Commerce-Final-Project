# SATURN Premium Game Store 🪐

Migrated from legacy HTML/CSS to **Vite + React + Tailwind CSS**.

## Features 🚀
- **Modern UI**: Full dark-theme design with Glassmorphism.
- **Responsive**: Works on mobile, tablet, and desktop.
- **Search & Filter**: Real-time game discovery.
- **Cart System**: Persistent shopping cart using LocalStorage.
- **Checkout**: QR Scan payment simulation (GCash/Maya ready design).
- **Database**: Simulated persistent database using LocalStorage (ready for API integration).

## Tech Stack 🛠️
- **Vite**: Ultra-fast build tool.
- **React**: Modern component-based architecture.
- **Tailwind CSS**: Utility-first styling.
- **Framer Motion**: Premium micro-animations.
- **Lucide React**: Beautiful icons.

## How to Run 🏃‍♂️
1. Ensure you have [Node.js](https://nodejs.org/) installed.
2. Open terminal in this folder.
3. Run `npm install` (if not already done).
4. Run `npm run dev`.
5. Open the link displayed in terminal (usually `http://localhost:5173`).

## Project Cleanup 🧹
- Old legacy files have been moved/removed to prepare for modern deployment.
- Deployment ready: Just run `npm run build` and upload the `dist` folder to Vercel, Netlify, or Hostinger.
